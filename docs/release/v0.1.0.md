## CtrlSW v0.1.0 — 첫 릴리스 (설계서 M1~M6)

전자전기(Stand Off Jammer)-레이다 시연용 제어 SW 의 첫 배포본입니다.

### 다운로드
- **`CtrlSW-v0.1.0-windows-x64.zip`** — 압축 해제 후 `CtrlSW.exe` 실행 (설치 불필요, Qt 6.8.3 / MSVC 런타임 포함). 사용법은 zip 안의 `README.txt`

### 주요 기능
- 벡터 지도(한반도 중심, 해안선·국경·행정구역·하천·산·군사분계선, 레이어 토글)
- 시나리오 편집: 레이다(최대 4) / 전자전기 / 아군편대(교란설정) / 단독허위표적(고정·이동·랜덤·잡음), 지도 클릭·드래그 편집, 항목별·전체 저장/불러오기
- 단독모드 시뮬레이션: 이동, 빔 회전(MainLobe 동기화), 편대 허위타겟, 자체 탐지 판정, 랜덤 고스트, 잡음섹터, 1/2/4/8 배속, 일시정지
- 연동모드: TCP 서버, 임무전송·시작·중지·위치 주기송신, MainLobe 수신 → 빔 동기화·탐지 전시, 송수신 로그
- 모의 클라이언트 `ctrlsw_mock.exe` (분석SW / 신호발생장치 에뮬레이터)

### 알려진 제한
- Command Code·payload 는 **협의 전 임시안** (`docs/ICD.md` 4장 협의 항목). 값 변경은 `protocol.json` 으로 재빌드 없이 가능
- 실장비 연동 시험 전
- 지도는 Natural Earth 10m 상세도 (시/군/구 경계 없음)
