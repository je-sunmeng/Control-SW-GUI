## CtrlSW v0.1.1

v0.1.0 과 기능 동일 + Windows 실행파일 속성(버전 정보) 추가.

### 다운로드
- **`CtrlSW-v0.1.1-windows-x64.zip`** — 압축 해제 후 `CtrlSW.exe` 실행 (설치 불필요, Qt 6.8.3 / MSVC 런타임 포함). 사용법은 zip 안의 `README.txt`

### 변경
- `CtrlSW.exe`, `ctrlsw_mock.exe` 에 VERSIONINFO (파일 버전 0.1.1, 제품명, 설명) 추가 — 탐색기 → 속성 → 자세히

### 포함 기능 (M1~M6)
- 벡터 지도, 시나리오 편집·저장/불러오기, 단독모드 시뮬레이션(빔·탐지·허위표적·잡음섹터·배속), 연동모드(TCP, 임무전송·시작·중지·위치 송신·MainLobe 수신), 모의 클라이언트 `ctrlsw_mock.exe`

### 알려진 제한
- Command Code·payload 는 협의 전 임시안 (`docs/ICD.md`), `protocol.json` 으로 재빌드 없이 변경 가능
- 실장비 연동 시험 전
