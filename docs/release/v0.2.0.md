## CtrlSW v0.2.0

사용자 수정 요청 11건 반영.

### 다운로드
- **`CtrlSW-v0.2.0-windows-x64.zip`** — 압축 해제 후 `CtrlSW.exe` 실행 (설치 불필요). 사용법은 zip 안의 `README.txt`

### 변경 사항
1. 지도 최대 축소를 지도 전체가 화면을 채우는 크기로 제한, 지도 밖으로 이동 불가
2. 임무 중에도 오브젝트 설정 창 스크롤 가능 (값 편집만 잠금)
3. 설정값 위에서 마우스 휠로 값이 바뀌지 않음 (휠 = 패널 스크롤)
4. 오브젝트 이름 "탐지기" → "레이다"
5. 전자전기 동선 **루프**: 마지막 점 → 시작점 자동 연결, 임무 중 반복 비행 (이전 버전 저장 파일도 루프로 변환)
6. 동선 입력 중 **우클릭 = 가장 최근에 추가한 점 삭제** (완료: 더블클릭 / Enter)
7. 전자전기 = 여객기 형상, 아군편대 = 전투기 형상
8. 레이다 메인로브 색상을 차분하게 (채도·밝기·투명도 낮춤)
9. 지도 이동 = **좌클릭 드래그** (핸들 위에서는 핸들 이동, 제자리 클릭 = 배치/웨이포인트)
10. 레이다 탐지 지점을 페이딩 없이 계속 표시 (새로고침 시 초기화)
11. 시나리오 "새로" 버튼 → "초기화"

### 프로토콜 변경
- JammerRoute: 루프 동선은 시작점을 마지막에 반복해 송신 (`docs/ICD.md`)
