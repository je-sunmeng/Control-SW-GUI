## CtrlSW v0.3.0

사용자 수정 요청 8건 반영.

### 다운로드
- **`CtrlSW-v0.3.0-windows-x64.zip`** — 압축 해제 후 `CtrlSW.exe` 실행 (설치 불필요). 사용법은 zip 안의 `README.txt`

### 변경 사항
1. 아군편대 설정창: 동선 테이블 높이가 구간 수에 맞춰 변함(최대 6행) → 아래 교란설정이 바로 보임. 동선 표는 `구간(WP1 → WP2) | 고도 | 속력` 으로 정리 (좌표는 툴팁)
2. 저장/불러오기 기본 경로 `문서\CtrlSW` 와 기본 파일명 `<종류>_<날짜>_<시각>` 지정. **파일 → 기본 저장 폴더 설정… / 저장 폴더 열기** 추가
3. 로그창 크기를 조절해도 전자지도 위치·배율이 바뀌지 않음
4. 설정값 ▲▼ 버튼·콤보 ▼ 를 밝은 화살표와 넓은 버튼으로 표시
5. **아군편대가 동선 끝에 도달하면 임무 종료(중지)** — 연동모드는 STOP 메시지 송신
6. 아군편대(전투기) 아이콘 축소, 편대 허위타겟을 편대 아이콘 위에 표시
7. 랜덤 허위표적 표시 변경: 레이다 색의 점선 링이 퍼지며 사라지는 블립 (탐지 점과 구분)
8. 마우스 휠로 설정값 입력칸이 선택(포커스)되지 않음
