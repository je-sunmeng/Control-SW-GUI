## CtrlSW v0.4.0

사용자 수정 요청 9건 반영.

### 다운로드
- **`CtrlSW-v0.4.0-windows-x64.zip`** — 압축 해제 후 `CtrlSW.exe` 실행 (설치 불필요). 사용법은 zip 안의 `README.txt`

### 변경 사항
1. 저장 폴더를 종류별로 분리: `문서\CtrlSW\레이다`, `전자전기`, `아군편대`, `단독허위표적`, `시나리오` (종류별 마지막 폴더 기억)
2. 데이터링크 구역을 제어 패널의 장치 연결 상태 아래로 이동, **연동모드에서만 표시**. **전자전기 위치 전송간격** 추가 (시나리오 파일에 저장)
3. Qt 경고 `Unable to open monitor interface to \\.\DISPLAY1` 원인 확인: Windows 에서 모니터 정보(EDID) 조회 실패 시 Qt 가 남기는 무해한 경고 → 오류가 아닌 "정보(Qt 경고)" 로 기록
4. 지도에 **독도** 추가 (섬 윤곽 + "독도"·"울릉도" 이름 표시)
5. 연동모드 MainLobe: 레이다별 **최초 수신 시점에만** 빔이 전자전기 방향에서 나타나 스캔 시작 (그 전에는 빔 미표시), 램프는 수신 후 계속 점등
6. MainLobe 미수신 레이다 이름은 어둡게 표시
7. MainLobe 램프 순서 = 오브젝트 목록의 레이다 순서 (삭제 시 뒤 레이다가 앞으로)
8. 단독모드에서 [임무전송] 버튼 숨김
9. 명칭 "신호발생장치" → **"재밍기법발생기"** (화면·로그·문서)
